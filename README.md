# 文京区 施設予約ねっと 部屋まとめ表示補助（Chrome拡張）

「文の京」施設予約ねっと（https://www.shisetsu.city.bunkyo.lg.jp/user/Home）で、
**日付と部屋を選ぶだけで、公式の「時間帯別空き状況」画面にその部屋だけをまとめて表示する**補助ツールです。

- 公式サイトの通常の検索手順（Home →「一覧から探す」→「全施設」→ 施設選択 → 施設別空き状況 → 時間帯別空き状況）を、公式画面のボタン操作で順に進めます。
- 時間帯の選択・ログイン・予約申込は**行いません**。表示された公式画面から、ご自身で続けてください。
- サーバーなし。認証情報・Cookie・予約内容の収集や外部送信はしません。

## 導入手順（Mac・Windows 共通、Chrome 114 以降）

1. このフォルダ（`manifest.json` があるフォルダ）を任意の場所に置く。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開く。
3. 右上の「デベロッパー モード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ。
5. ツールバーのパズルアイコンから「文京区 施設予約ねっと 部屋まとめ表示補助」をピン留めすると使いやすくなります。

更新したときは、`chrome://extensions` でこの拡張の「再読み込み」（↻）を押してください。

## 使い方

1. ツールバーの拡張アイコンを押す。
2. 利用日を選ぶ（開くたびに日本時間の当日が入ります）。
3. 見たい部屋にチェックを入れる（**最大10部屋**。理由は下記）。前回のチェックは自動で復元されます。
4. 「公式サイトで表示」を押す。
   - 公式サイトのタブを開いていればそのタブで、なければ新しいタブで Home から操作を始めます。
5. 画面右上に進行状況が出ます。終わると時間帯別空き状況画面になり、右上に小さな**部屋まとめ（比較ビュー）**が出ます。
6. 比較ビューで空き枠を見比べます。枠をクリックすると、下の公式画面の同じ枠が選択／解除されます。
7. 公式画面右下の「次へ進む」から予約操作を続けます（未ログインならログイン画面が出ます）。

### 比較ビュー（部屋まとめ）

公式の時間帯別空き状況画面は施設ごとに時間軸が分かれて縦に並ぶため、部屋同士を見比べにくくなっています。
比較ビューは、**公式画面が既に表示している内容だけ**を読み取り、全部屋を共通の時間軸（例: 8:00〜22:00）に並べ直したものです。

- 枠の区切り（午前／午後Ⅰ／午後Ⅱ／夜間など）は施設ごとに違うため、時刻どおりの位置と幅で並べます。
- 状態（○空き・×空きなし・－期間外など）は公式表示のまま。マウスを重ねると時刻と状態が出ます。
- **斜線＋点線の枠**は「公式画面では○だが、今は選択できない枠」です（公式の注意書き「ログイン後も〇をクリックできない場合は申込期間外」にあたる状態）。押すと理由を表示します。
- 選べる枠を押しても公式画面側の選択が切り替わらなかった場合は、パネル上部にその旨を表示します。
- 枠のクリックは公式画面の同じ枠をクリックするだけです。選択状態の正は常に公式画面で、ビューはそれを読み直して表示します。
- 独自の通信はしません。申込ボタンも置きません（申込は公式の「次へ進む」から）。
- 公式画面を隠さないよう右上に小さく固定表示します。「畳む」でタイトルだけの小さな表示になり、右下の角をドラッグすると大きさを変えられます。時間帯別空き状況画面を手動で開いた場合も表示されます。

### 状態表示

| 表示 | 意味 |
|---|---|
| 実行中: ＜段階＞ | 自動操作中。画面を触らずお待ちください。「中止」で止められます |
| 完了 | 指定日・指定部屋がすべて表示されたことを照合済み |
| 失敗: ＜段階＞ | その段階で停止。理由（見つからない施設・部屋、公式のエラー文言など）を表示。公式画面は変更せずそのまま |
| 中止しました | 利用者が中止 |

一部の部屋だけ選べた状態を「完了」とは表示しません。選べなかった部屋を「空きなし」とも解釈しません。

### 休館日など、その日に選べない部屋

公式の施設別空き状況で選択できない状態（例: 休館）の部屋は、**その部屋だけ除外して残りで続行**します。
完了表示と比較ビューの下端に「表示対象外: シルバーセンター シルバーホール — 休館」のように理由付きで出します。
選んだ部屋がすべて選べない場合は「失敗」で停止します。

### シビックセンター「4階ホール」の対応

公式上は次の2つが存在します。どちらも定員105名・文京シビックセンター内です。

- **シルバーセンター「シルバーホール」**（施設3・部屋1）← 本ツールはこちらを採用（利用者の判断）
- 区民会議室「４階ホール」（施設1・部屋11）

同じ部屋が別の申込区分で登録されている可能性がありますが、公式画面からは同一の部屋かどうかを断定できません（未確認）。
区民会議室側に戻す場合は `src/rooms.js` の `civic-4f-hall` 行を
`facilityCode: '1', objectCode: '11', officialName: '４階ホール'` に替え、`FACILITIES` の施設3を施設1（区民会議室）に替えてください。

## 公式サイトの制約（調査で判明）

- **一度に選べるのは最大10コマ**。施設別空き状況で11件以上選んで「次へ進む」を押すと、公式が
  「選択可能数は、最大10件までです。」とエラーを出します（実画面で11件→エラー、10件→通過を確認）。
  1日表示では1部屋＝1コマのため、**対象11部屋を一度に全部は表示できません**。
  本ツールは11部屋すべてをチェックリストに出し、「全選択」も使えますが、10部屋を超えると実行ボタンを無効にして理由を表示します。
- 施設一覧は最初10件だけ表示され、「さらに読み込む」（全81施設で8回）で残りが出ます。本ツールは全件表示してから操作します。
- チェックを短い間隔で連続して切り替えると、画面上はチェック済みでも公式側に反映されない事例を確認しました。
  そのため1件ずつ「操作 → 反映確認 → 少し待つ」で進め、最後に全体を再確認しています。
- Home →「全施設」から入ると、前回の施設選択はリセットされます（毎回 Home から始める理由）。

## 構成の比較と採用理由

| 案 | 遷移をまたぐ継続 | 前回選択の保存 | 導入 | 判定 |
|---|---|---|---|---|
| ブックマークレット | ✕ 画面遷移のたびにスクリプトが消え、毎回押し直しが必要 | △ 公式サイト側の保存領域を使うことになる | ◎ | 不採用 |
| ユーザースクリプト（Tampermonkey 等） | ○ | ○ | △ 別の拡張の導入が前提 | 不採用 |
| **Chrome拡張（MV3, サーバーなし）** | ○ background が段階を保持 | ○ `chrome.storage.local` | ○ フォルダを読み込むだけ | **採用** |

公式の流れは4画面にまたがり、途中画面の URL 直行はエラーになるため「画面遷移をまたいで手順を継続できること」が必須です。
これを追加の依存なしで満たす最小構成が Chrome 拡張でした。

### 比較ビューの方式（追加要件）

当初は「独自の空き状況一覧画面は作らない」方針でしたが、公式の時間帯別画面が施設ごとに分かれて比較しづらいため追加しました。

| 案 | 予約の継続 | 独自取得 | 判定 |
|---|---|---|---|
| **公式の時間帯別画面に比較パネルを重ねる** | ◎ 同じ画面の「次へ進む」 | なし（描画済みの内容を読むだけ） | **採用** |
| 拡張の別ページに表示 | △ 元のタブに戻る必要 | なし | 不採用 |
| 内部通信で独自に取得して一覧化 | ✕ 予約に繋がらない | あり（「未確認の内部通信を前提にしない」に反する） | 不採用 |

## 未確認事項

- **ログイン後の選択引継ぎ**: 時間帯別画面で「次へ進む」→ ログイン後に、選んだ部屋・日付が維持されるかは未検証です（ログイン操作は対象外のため）。
- **拡張として読み込んだ状態での通し動作**: 上記の検証は画面操作部分を実サイトへ注入して行ったもので、`chrome://extensions` から読み込んだ状態（ポップアップ → background → タブ遷移）の通し確認はまだです。初回はご自身の Chrome で1度お試しください。
- **Windows での動作**: Mac の Chromium 系ブラウザでのみ確認。OS 固有の処理はありません。
- **抽選期間・施設に問合せ・利用時間外のコマ**: これらの状態の日付では未確認です。施設別空き状況で選択できない状態なら、休館と同様に理由付きで除外します。比較ビューでの色分けは、公式の状態名を推定で対応づけています（未知の状態は記号のまま表示）。
- **比較ビューの見た目**: 幅1280px前後の画面で確認。狭い画面では横スクロールになります。
- **通信失敗・セッション切れ・メンテナンス画面**: 実際には発生させていません。想定外の画面・要素待ちの時間切れとして停止する作りです。

## 将来の変更時の注意

- 部屋の追加・改称: `src/rooms.js` だけを直します。公式コードは施設別空き状況画面のセルの hidden 値（`...ObjectCode[0]`）で確認できます。
- 公式画面の改修で、ボタン名（「一覧から探す」「全施設」「さらに読み込む」「次へ進む」「表示」「1日」）や
  hidden 項目名（`SelectedFacility.Value`、`AvailabilitySelectDays...`、`AvailabilityTime.FacilityList...`）が変わると停止します。
  停止時の表示に段階が出るので、`src/content.js` の該当段階を直してください。
- 公式の上限（10件）が変わったら `src/rooms.js` の `MAX_SELECTABLE` を変更します。
